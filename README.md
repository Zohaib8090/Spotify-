# Spotify MCP (hosted on Render)

Control your Spotify from Claude, ChatGPT, and Grok: playback, queue, playlists,
library, follows, top items, history. About 36 tools. No database; logins are encrypted
blobs, so restarts never sign you out.

## Deploy

1. Push this folder to a GitHub repo (private is fine).
2. Render dashboard > New > Blueprint > pick the repo. It reads `render.yaml`.
3. Set `SPOTIFY_CLIENT_ID` when asked. Leave `SECRET_KEY` as generated. Set
   `ALLOWED_SPOTIFY_USER_IDS` to your Spotify username/id (profile > share > the id in the link).
4. When the deploy is live, note the URL, for example `https://spotify-mcp-abcd.onrender.com`.
5. In the Spotify developer dashboard, add this Redirect URI to your app and save:
   `https://spotify-mcp-abcd.onrender.com/spotify/callback`  (use your real URL)
   Also add your own Spotify account under User Management.
6. Add the server as a custom connector in your supported client:
   - Claude: `https://spotify-mcp-abcd.onrender.com/mcp`
   - ChatGPT: `https://spotify-mcp-abcd.onrender.com/mcp`
   - Grok: `https://spotify-mcp-abcd.onrender.com/mcp`
   Connect, log in to Spotify, press Agree.

If Render gave your service a different URL than you expected, set the `PUBLIC_URL`
env var to it exactly (https, no trailing slash).

## Notes

- Free Render services sleep when idle. The first request after a sleep takes about 30-60 s;
  if the connector times out, just retry. `starter` plan keeps it awake.
- Playback commands need an active Spotify device (open the Spotify app once).
- Revoke access any time: Spotify account > Apps > remove. Changing `SECRET_KEY` logs out all clients.
- Spotify may restrict some Web API endpoints for development-mode apps. Errors are returned
  to the AI client as text rather than crashing.
- Test locally with Spotify mocked: `pip install -r requirements.txt && python test_flow.py`

## Env vars

| name | purpose |
|---|---|
| SPOTIFY_CLIENT_ID | your Spotify app's Client ID (no secret needed, PKCE) |
| SECRET_KEY | encrypts tokens (auto-generated by render.yaml) |
| PUBLIC_URL | optional; defaults to Render's `RENDER_EXTERNAL_URL` |
| ALLOWED_SPOTIFY_USER_IDS | optional but recommended allowlist |
| ALLOWED_REDIRECTS | optional; defaults to supported connector callback URLs for Claude, ChatGPT, and Grok |
